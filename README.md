# Retail Sales & Customer Analytics

##  Project Overview

This project analyzes retail sales and customer data using **MySQL**. The goal is to explore sales performance, customer behavior, product performance, regional trends, and profitability through SQL queries.

The project uses a relational database consisting of four tables:

* `customers`
* `products`
* `orders`
* `order_details`

The analysis includes **40 SQL business questions** covering basic to advanced SQL concepts such as aggregations, joins, subqueries, CTEs, and window functions.

##  Database Schema

### 1. Customers

Stores customer information.

| Column          | Description                |
| --------------- | -------------------------- |
| `customer_id`   | Unique customer identifier |
| `customer_name` | Customer name              |
| `gender`        | Customer gender            |
| `age`           | Customer age               |
| `city`          | Customer city              |
| `region`        | Customer region            |

### 2. Products

Stores product information.

| Column         | Description               |
| -------------- | ------------------------- |
| `product_id`   | Unique product identifier |
| `product_name` | Product name              |
| `category`     | Product category          |
| `sub_category` | Product sub-category      |
| `price`        | Product price             |

### 3. Orders

Stores order-level information.

| Column           | Description                   |
| ---------------- | ----------------------------- |
| `order_id`       | Unique order identifier       |
| `customer_id`    | Customer who placed the order |
| `order_date`     | Date of the order             |
| `payment_method` | Payment method used           |

### 4. Order Details

Stores product-level details for each order.

| Column            | Description                    |
| ----------------- | ------------------------------ |
| `order_detail_id` | Unique order-detail identifier |
| `order_id`        | Related order                  |
| `product_id`      | Related product                |
| `quantity`        | Quantity purchased             |
| `discount`        | Discount applied               |
| `profit`          | Profit generated               |

---

## 🔗 Table Relationships

```text
customers
    │
    │ customer_id
    ▼
  orders
    │
    │ order_id
    ▼
order_details
    │
    │ product_id
    ▼
 products
```

### Relationships

* One customer can place multiple orders.
* One order can contain multiple order-detail records.
* One product can appear in multiple order-detail records.
* `customers.customer_id` → `orders.customer_id`
* `orders.order_id` → `order_details.order_id`
* `products.product_id` → `order_details.product_id`

##  Sales Definition

For this project:

**Total Sales = Product Price × Quantity Sold**

The `discount` column is available in the dataset, but total sales in this analysis is calculated using the product price and quantity sold.

##  Business Questions Analyzed

### Sales & Performance

1. What is the total sales/revenue generated by the company?
2. What is the total profit generated by the company?
3. How many orders has the company received?
4. How many units of products have been sold?
5. What is the average amount spent per order?
6. How much sales revenue did each product category generate?
7. How much total sales did each region generate?
8. Which product generated the highest sales revenue?
9. What are the top 3 products by total sales revenue?
10. How much sales revenue did the company generate in each month?

### Regional & Customer Analysis

11. How many orders were placed from each region?
12. What is the average order value for each region?
13. Which product generated the highest total profit?
14. Which customers have placed more than one order?
15. Which customer has spent the most money?
16. Which customers have never placed an order?
17. Which product category sold the highest number of units?
18. Which product category generated the highest total profit?
19. What is the average age of customers in each region?
20. Which customer has placed the most orders?

### Product & Customer Behavior

21. Which product was ordered most frequently?
22. Which products have never been ordered?
23. Which customer generated the highest total profit?
24. What is the profit margin for each product category?
25. How many customers have placed more than one order?
26. Which month generated the highest sales?
27. Which month generated the highest total profit?
28. For each product category, what are the total sales, total profit, and profit margin?
29. Which customers have total spending greater than the average customer spending?
30. Who are the top 3 customers by total profit?

### Advanced SQL Analysis

31. Which customer has the second-highest total spending?
32. What percentage of total company sales comes from each product category?
33. Which product category has the highest profit margin?
34. Which product generated the second-highest total profit?
35. Which customers generated total profit of 0 or less?
36. What is the highest-selling product within each category?
37. What is the first order date for each customer?
38. What is the latest order date for each customer?
39. Which customers placed orders in more than one month?
40. Which product category has the highest sales among categories with a profit margin greater than 15%?
